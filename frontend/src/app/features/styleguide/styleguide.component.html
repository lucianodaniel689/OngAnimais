Botões

Variantes do Material

Ação destrutiva: o tema M3 ignora color="warn" — use a classe global .botao-perigo num mat-flat-button (regra em _base.scss, tokens --cor-perigo). Sempre acompanhada do diálogo de confirmação.

Com ícone

Passe o mouse em qualquer botão acima: todo `mat-button`/`mat-icon-button`/`mat-fab`... já "levanta" levemente no hover (regra global em _base.scss, sem precisar de classe extra) — soma ao ripple padrão do Material.

Loading

Componente próprio app-loading — indicador de carregamento padrão do sistema: use em qualquer lista, formulário em modo de edição ou seção pública que espera dados assíncronos, em vez de montar mat-progress-spinner "na mão". Não é para spinner inline em botão de submit (esse continua pequeno, direto no botão).

Troca de página no /admin também mostra uma barra de progresso fina no topo enquanto a rota (e o chunk lazy) carrega — ver AppComponent.

Stat tile (KPI)

Componente próprio app-stat-tile — rótulo + valor em destaque + ícone, com variantes de cor (mesmos tokens dos badges de status). Usado no dashboard administrativo. Passe rota para o tile inteiro virar um link — e, opcionalmente, queryParams para a lista de destino abrir já filtrada (é assim que os KPIs do dashboard abrem cada lista com o mesmo filtro que gerou o número).

Upload de imagens

Componente próprio app-upload-imagens (o Material não tem dropzone): drag & drop ou clique para selecionar, com validação de tipo/tamanho no cliente. Usado em AnimalFotosComponent (galeria de fotos no formulário de animal).
